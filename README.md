## 📖 Sobre o projeto

O **ROOSemProblemas** é uma plataforma desenvolvida como projeto acadêmico no **Instituto Federal de Mato Grosso (IFMT)** com o objetivo de facilitar a comunicação entre a população e a administração pública.

A aplicação permite que cidadãos registrem problemas urbanos, como:

- 🕳️ Buracos em vias públicas
- 💡 Iluminação pública
- 🌳 Limpeza e manutenção
- 🚦 Sinalização
- 🚰 Vazamentos
- 📍 Outros problemas urbanos

Cada ocorrência possui localização, descrição, imagens e acompanhamento do seu status.

---

## 🎯 Objetivo

Criar uma ferramenta simples, acessível e eficiente para aproximar cidadãos do poder público, tornando o processo de denúncia e acompanhamento muito mais transparente.

# 📱 Protótipo

O protótipo da interface foi desenvolvido utilizando **Figma**, seguindo princípios de Design Thinking e testes de usabilidade com a metodologia **System Usability Scale (SUS)**.

---

# 📊 Pesquisa

Antes do desenvolvimento foi realizada uma pesquisa com moradores de Rondonópolis para identificar os principais problemas enfrentados pela população.

Os resultados serviram como base para definição das funcionalidades da aplicação.
